# Run of Show Model



## Live Progress Layer

The Run of Show must be treated as the live operating spine of each event.

Each segment should support both planning fields and live execution fields.

### Planning Fields

- segment title
- public title
- start time
- end time
- duration
- room/stage
- speaker
- sponsor
- assets
- poll cue
- Q&A cue
- technical cue
- producer notes
- backup plan
- client approval status

### Live Execution Fields

- live status
- live readiness status
- actual start time
- actual end time
- delay minutes
- live notes
- emergency notes
- last updated by
- last updated at

### Required Live Views

- current segment
- previous segment
- next segment
- next three cues
- completion percentage
- on-time / monitor / behind / blocked status
