# Speaker Teleprompter

## Purpose

The teleprompter lets a speaker use the approved live version of their script during the event.

## Rules

- Speakers may submit edits.
- Edits create new versions.
- The approved live version remains active until producer approval.
- Producer can approve as live, approve as speaker-only note, or reject.
- Rollback must always be available.

## MVP Controls

- Current approved script
- Pending script version
- Font-size shell
- Scroll-speed shell
- Dark-mode shell
- Full-screen shell later

## Deferred

AI script writing, real file upload, full-screen prompter controls, and synchronized producer-pushed overlays.
