# Sponsor Self-Serve

## Purpose

Sponsors need a direct way to submit package deliverables without forcing producers to chase every logo, CTA, rep name, and PDF manually.

## Sponsor Can Submit

- logo
- booth headline
- booth description
- CTA label
- CTA URL
- offer text
- resource PDF
- promo video
- representative names/emails
- lead routing email
- demo/calendar link
- giveaway details
- sponsor session details
- run-of-show mention copy

## Sponsor Cannot Do

- change package tier after lock
- publish booth without approval
- access other sponsor metrics
- access private attendee data
- change run-of-show timing
- see agency internal notes
