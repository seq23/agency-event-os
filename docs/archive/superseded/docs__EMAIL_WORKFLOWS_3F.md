# Batch 3F — Resend Invites and Reminder Workflow Foundation

## Purpose

Define the email workflow layer without requiring production Resend sending yet.

## Workflows

- client invite
- speaker invite
- sponsor setup invite
- contractor assignment
- approval request
- changes requested
- tech-check reminder
- asset deadline reminder
- show-day reminder
- testing failure alert
- report ready

## Manual Resend Setup

Resend domain verification, API key, EMAIL_FROM, reply-to, and DNS records can wait until real sending is turned on.
