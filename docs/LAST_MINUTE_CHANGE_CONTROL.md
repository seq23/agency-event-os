# Last-Minute Change Control

## Purpose

Speakers and sponsors will make changes close to showtime. The system must turn those changes into controlled, reviewable, versioned decisions.

## Rules

1. Never overwrite locked assets.
2. Every late edit creates a new version.
3. Approved version remains live until producer pushes a new version.
4. Changes inside 60 minutes require producer approval.
5. High-risk changes require client approval or explicit producer override.
6. During live segments, destructive replacement is blocked.
7. Every live push is audit logged later.
8. Rollback must always be available.
9. Speaker sees what version is live.
10. Production team sees what changed and what it affects.

## Statuses

draft, submitted, triage_needed, producer_review, client_review_required, client_review_skipped, approved, approved_with_conditions, rejected, locked, pushed_to_live, used_live, rolled_back, archived.
