# Speaker Approval Workflow

## Speaker Submits

- headshot
- bio
- talk title
- talk description
- deck
- script
- talking points
- release form
- pronunciation notes
- AV needs

## Review Owners

Agency reviews technical fit and production readiness. Client reviews brand-sensitive public content where required. Producer locks final live use.

## Statuses

not_requested, requested, submitted, agency_review, client_review, changes_requested, approved, locked, ready_for_live.
