# West Peek Live! Brand System

## Status

Locked pre-deployment brand contract.

## Official product name

West Peek Live!

The prior product name, Agency Event OS, is deprecated for user-facing use.

## Wordmark contract

The wordmark is a text-first lockup:

- `West Peek` is bold, clean, black, modern sans-serif.
- `Live!` is always orange.
- `Live!` is always a different font family: script, handwritten, or neon-sign style.
- `Live!` must be visually skewed, slightly lowered, and attached to the same wordmark line.
- `Live!` must not sit flat on the same baseline.
- `Live!` must not appear on a separate clean second line unless it is visibly hanging from the `k` in `Peek`.

## Palette

| Token | Value | Usage |
| --- | --- | --- |
| Black | `#050505` | Primary text, sidebar, hero surfaces |
| White | `#ffffff` | Cards, email body, high-contrast surfaces |
| Charcoal | `#171717` | Secondary dark surface |
| Ash | `#f5f3ef` | Page background |
| Line | `#e7e3dc` | Borders |
| Muted | `#73706a` | Secondary text |
| Orange | `#f05a1a` | `Live!`, CTA accents, active state, live status |

## Usage rules

Orange is an accent, not a background system. Use it for:

- the `Live!` word
- primary highlights
- CTA hover states
- live production status
- important event-state cues

Do not use generic blue/purple SaaS styling for primary brand surfaces.

## Product tone

West Peek Live! should feel:

- premium
- calm
- operational
- high-trust
- live-production ready
- black/white first
- orange only where it matters

## Forbidden treatments

- Same-font `Live!`
- Black `Live!`
- Flat same-baseline `Live!`
- Generic stacked SaaS lockup
- Overuse of orange
- Bright blue/cyan primary styling
- Casual event-party visuals

## Email branding

Email templates must use:

- `West Peek Live!`
- black/white/orange styling
- rounded black CTA buttons
- reply-to identity configured through env


## Cross-suite canonical authority

This repo-specific treatment is subordinate to [`WEST_PEEK_BRAND_SYSTEM.md`](../WEST_PEEK_BRAND_SYSTEM.md). The canonical West Peek Orange is `#F05A1A`; black/white remain primary and orange remains an accent.
