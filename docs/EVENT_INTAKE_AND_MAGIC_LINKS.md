# Event Intake and Magic Links

## Event ID

Each event gets a human-readable Event ID such as NOVA-2026-SUMMIT.

Used for:

- email subject lines
- manual matching
- support
- producer reference
- asset intake
- magic links

## Magic Links

Role-specific links can be generated for:

- speaker upload
- sponsor setup
- client approval
- contractor call sheet

## MVP

Mock links only. Real tokens, expiry, revocation, and audit logging come after Supabase Auth.
